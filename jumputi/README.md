# ジャンプチ ヒーローズ 再現版（ファンメイド）

2024年3月にサービス終了したパズルRPG「ジャンプチ ヒーローズ」を、個人で遊ぶために再現した非公開のファンメイド作品です。
キャラ名・必殺ワザ名・作品名は原作どおり。絵はプログラムで描いたちびキャラで、キャラ詳細の「画像を変更」から自分で用意した画像に差し替えられます（画像は端末のブラウザ内にだけ保存）。

## 遊び方
`index.html`（または1ファイル版の `jumputi-single.html`）をブラウザで開くだけで遊べます（スマホ縦画面向け・ビルド不要）。データはブラウザ（localStorage）に保存されます。

## 再現したシステム
- **プチ**: 赤・緑・青・黄・ハートの5種類。タップするとつながった同じ色がまとめて割れる（1個からOK）
- **4人パーティ**: メイン4人が1人1回ずつ順番にプチを割り、全員の行動後に一斉攻撃
- **同色ボーナス**（攻撃1.5倍）、**属性相性** 赤→緑→黄→青→赤（有利1.3倍／不利0.7倍）、ハートで回復
- **必殺プチ**: 7個以上つなげると、タップ位置から一番遠い場所に出現。爆発範囲は割った数で拡大し、範囲内の必殺プチは誘爆。顔のキャラの必殺ワザがカットイン付きで発動
- **特性**（例: ルヒィはHP90%以上で必殺プチ生成-1・攻撃5%UP）
- **サポート**: メイン1人につき3枠。ステータスの一部を加算（同属性は多め＋属性ブースト）、友情枠のキャラの**友情ワザ**はターン経過で「GO!」
- **レジェンド召喚**: プチを割るとゲージがたまり、満タンで全体攻撃（行動を消費しない）
- 邪魔プチ・虹プチ、友情ワザ封印、次に落ちてくるプチの予告表示
- 敵の行動ターン表示、ウェーブ制、ボス戦、タップでターゲット指定
- **クエスト** 8エリア×5ステージ＋修行の間、スタミナ、ランク、ルビー、ログインボーナス、ミッション
- **ガチャ**（10連で★5確定、ピックアップ）、重複で限界突破・ワザLvアップ、コインでレベルアップ
- オートバトル、バトル速度×1〜×3、効果音

## ファイル構成
| ファイル | 内容 |
|---|---|
| `js/art.js` | ちびキャラ・モンスター・背景のSVG生成 |
| `js/data.js` | キャラ・レジェンド・敵・クエスト・ガチャ・ミッションのデータ |
| `js/battle.js` | パズルバトル本体 |
| `js/screens.js` | タイトル・ホーム・クエスト・編成・キャラ・ガチャ・リザルト画面 |
| `js/save.js` | セーブデータ |
| `js/util.js` | 共通処理・効果音 |
